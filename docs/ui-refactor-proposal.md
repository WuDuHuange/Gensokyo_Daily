# 幻想乡日报 · UI 重构方案

> 状态：**提案，未执行任何改动**
> 日期：2026-09-29
> 核查基准：`index.html` / `css/input.css`（1025 行）/ `js/app.js`（840 行）/ `js/motion.js`（300 行）/ `news_data.json`（115 条）

---

## 0. 结论

「感觉一般」的根因不是配色不好看，而是：

1. **版面是「7 个全宽区块竖着摞」，不是报纸版面。** 报纸感全靠字体、双线、噪声堆出来，版面本身没有张力——字号有层级，**版面没有**。
2. **强调色被用成了背景色。** `#8B0000` 同时承担 7 种职责，一种颜色无处不在 = 没有强调。
3. **20+ 个彩色 emoji 破坏了整份报纸的调性**，改动成本最低、收益最大。

外加 **6 个硬伤**，其中 1 个正在头条上现形。

推荐做法：**保留「报纸」身份，重排结构 + 重定配色 + 清掉 emoji**（下文的 **T1**）。不建议换隐喻。

## 2. 配色方案

### 2.1 令牌收敛：13 → 7

当前 13 个令牌中，**线色与链接色可以取消**：

- `rule-color` / `rule-light` → 改为由墨色透明度派生（`ink @ 12%` / `ink @ 28%`）
- `link-color`（`#1A3A5C` 藏青）→ 与「墨 + 朱」双色体系冲突，正文内链接直接用朱色 + 下划线
- `fiber` → 并入 `paper-2` 的派生值

结果：**全页只剩「墨」「朱」两个色相**，符合双色印刷的报纸传统。

### 2.2 日刊 · 纸张

| 令牌 | 值 | 实测对比度 | 用途 |
|---|---|---|---|
| `--paper` | `#FAF7EF` | — | 纸张主体 |
| `--paper-2` | `#EFE9DC` | — | 次级面、悬浮 |
| `--page` | `#C4BAA1` | 桌/纸分离 **1.80:1**（当前 1.42:1） | 桌面底色 |
| `--ink` | `#16140E` | **17.20:1** | 标题、正文 |
| `--ink-2` | `#555146` | **7.40:1** | 摘要、次要正文 |
| `--ink-3` | `#706B5F` | **4.96:1** | 元信息（满足 AA 4.5:1） |
| `--seal` | `#B23A2E` | **5.54:1** | 朱：标记 / 链接 / 印章 |

对比当前：`ink-light` 3.11:1 → `ink-3` 4.96:1，**首次达标**。纸张从偏黄泛褐的 `#F5F0E1` 提亮到 `#FAF7EF`，桌面同时降饱和加深，**桌纸分离度从 1.42:1 提到 1.80:1**，「纸浮在桌上」的错觉才立得住。

### 2.3 夜读 · 灯笼

| 令牌 | 值 | 实测对比度 |
|---|---|---|
| `--page` | `#0A0908` | — |
| `--paper` | `#1E1B16` | — |
| `--paper-2` | `#262219` | — |
| `--ink` | `#EDE6D5` | **13.80:1** |
| `--ink-2` | `#BCB4A0` | **8.32:1** |
| `--ink-3` | `#8C8575` | **4.68:1** |
| `--seal` | `#D66048` | **4.60:1** |

**夜间的一个设计决定**：深色下纸/桌分离度物理上限约 1.2:1，做不出「纸浮在桌上」。所以夜间**主动放弃这个错觉**——去掉外阴影，改用 `1px` 边框 + `--paper-2` 的内嵌面来划分层次。当前夜间靠 `--shadow-paper`（0.55 黑）硬撑，在近黑底上其实看不见，属于无效装饰。

朱色从当前的肉粉 `rgb(212 130 106)` 改为 `#D66048`，回到「印泥」而不是「褪色番茄」。

### 2.4 强调色收敛规则

朱色**只允许出现在 3 个位置**：

1. 区块标记（替代 emoji）
2. 链接（含 hover 下划线填充）
3. 印章 / 首字下沉

其余 4 处（滚动进度条、天气温度、广告副标题、focus 环）全部改用墨阶。滚动进度条改为 `--ink-3`，focus 环改为 `--seal` 但降为 1px 内描边。

## 3. 结构方案

### 3.1 从「区块竖摞」到「报版网格」

核心变化：**把栏从「区块内部」提到「页面层」**，让不同区块的栏目在同一行里咬合。

```
┌──────────────────────────────────────────────┐
│ 报头（刊名 / 期号 / 天气 / 主编）              │
├──────────────────────────────────────────────┤
│ 天气带（单行，8 地点均分，不折行）             │
├───────────────────────────┬──────────────────┤
│ 头条（跨 6/12 栏，首字下沉）│ 要闻 2 条（右栏） │
│                           ├──────────────────┤
│                           │ 简讯竖排 3 条     │
├───────────────────────────┴──────────────────┤
│ 简讯 · 四栏密排（补满 12~16 条）              │
├──────────────────────────────────────────────┤
│ 社会·民生（左 3 图卡 + 右 2 栏文字流）        │
├──────────────────────────────────────────────┤
│ 副刊 · 横向剪报条（3~4 张错落）               │
├──────────────────────────────────────────────┤
│ 分类广告 · 窄条（视觉重量最低）               │
└──────────────────────────────────────────────┘
```

### 3.2 逐区块改动

| 区块 | 当前 | 改为 | 解决的缺陷 |
|---|---|---|---|
| 报头 | 毛笔字 + 假名注音，注音与标题笔画相叠 | 宋体特粗（Noto Serif SC 900）+ 手写体只用于「文々。新聞」副标；注音改 `ruby-position: under` 或移除 | S6 / S9 |
| 天气 | flex-wrap 折 4+4，竖线起点不齐 | 固定 8 列 grid（`repeat(8, 1fr)`），窄屏降为 2 行时用 grid 分隔线而非 `border-left` | H2 |
| 头版 | 全宽；头条 + 3 要闻 + 6 简讯（简讯溢出到别的 section） | 头条跨 6 栏 + 右栏 2 要闻 + 3 简讯竖排；**「官方」section 不再向 `#container-brief` 写数据**（跨 section 写 DOM 是 leaky abstraction） | S1 / H5 |
| 简讯 | 3 栏 6 条 | 4 栏 12~16 条，来源标签只在**变化时**显示 | H5 |
| 社会·民生 | 50 条全走一行式 | 前 3 条带图卡（16:10）+ 其余 2 栏标题流，**用上已有的 32 张图** | H4 |
| 副刊 | 12 张等权宝丽来，同角色连排 | 横向剪报条 3~4 张（宽高比统一，靠宽度做错落）；加入**邻域去重**（同 source 连续 2 条只取 1） | H3 / S1 |
| 广告 | 全宽 4 栏大卡 | 底部窄条，字号降一档 | S1 |
| 工具坞 | 4 个圆形 emoji 按钮，压在正文上 | 收起为单按钮展开式；图标改 SVG | S3 |

### 3.3 响应式

- ≥1024px：完整 12 栏报版
- 768–1023px：降为 8 栏，头条独占整行
- <768px：**单栏线性**，去掉所有多栏咬合（报纸版式在手机上没有意义，此时应退化为「干净的阅读流」，而不是把 12 栏硬压成 1 栏）

## 4. 调性：emoji 清理

全部 20+ 个 emoji 换成 **1.5px 描边的线性 SVG 图标**（内联，不引外部依赖）：

| 位置 | 当前 | 改为 |
|---|---|---|
| 区块头 ×5 | 📰📌💬🎨📋 | 5 个线性图标（报纸 / 书签 / 对话框 / 画笔 / 方框） |
| 天气 | ☀️⛅🌸🌫️🌀 | 保留 emoji —— 天气图标有语义、面积小、且 `weather-icon` 已显式指定 emoji 字体栈规避豆腐块 |
| 广告 | 🔧💊🏪⛩️ | 换为线性图标 |
| 工具坞 | 🌙🔇🎵↑ | 换为线性图标 |
| 页脚/空状态 | 📭 | 换为线性图标 |

天气是唯一保留 emoji 的位置，理由是它承担实际语义而非装饰。

## 5. 字体

| 用途 | 当前 | 改为 | 理由 |
|---|---|---|---|
| 报头刊名 | `Ma Shan Zheng`（毛笔行书） | `Noto Serif SC 900` | 真报纸刊头是宋体/黑体特粗，毛笔行书更像招牌而非报头 |
| 手写体 | 无 | `Ma Shan Zheng` 仅用于「文々。新聞」副标与首字下沉 | 保留笔触感，但不承担主视觉 |
| mono | `Courier New`（无 CJK，中英混排基线不齐） | 系统栈 `ui-monospace, "Cascadia Mono", Consolas, monospace` + **只在纯 ASCII 上使用** | 消除 fallback 导致的基线跳动 |
| 正文 | `Noto Serif SC`（Google Fonts） | 自托管 `woff2` 子集 | Pages 上首屏 FOUT；国内 Google Fonts 不稳 |

字体子集化：正文只用到常用 3500 字，子集后单字重约 400–600KB，两个自托管文件即可覆盖。

### T2 的论点与反驳

**论点**：报纸隐喻天然是「一天一份、线性、按重要性排序」，而这里的数据是「每小时刷新的 115 条流」。用报纸装流是错配——这正是「简讯塞不满」「副刊像图库」的根因。

**反驳**：「幻想乡日报 / 射命丸文 / 天狗新闻」是这个项目的**身份**，也是它在作品集里唯一的辨识度来源。换成「手账」或「现代编辑排版」，得到的是一个好看但普通的卡片流，丢掉的比得到的多。数据形态的问题，靠 T1 的「分层 + 密度控制」就能解决，不需要换魂。

### 支持 T1 的理由

- T0 是**纯赚**：修 44% 条目的显示 bug，没有理由不做。
- T1 的成本集中在 `app.js` 渲染层，而这部分**本来就有 5 个已知缺陷**（H2~H5 + S8）。重构顺带全修 → 这不是「为了好看重做」，是「修 bug 的副产品是新版面」。
- `motion.js` 的动效约定（`html.js` 渐进增强、`translate` 而非 `transform`、`prefers-reduced-motion` 降级）可以原样保留，重构不会碰到动效层。

- 如果这个项目**已经交完作业 / 只是自己看**，T1 的边际收益有限，T0 就够了。
- 重构期间页面会有几天处于半成品状态，需要接受「本地能跑、线上还是旧版」的窗口期。

## 9. 明确不做的事

- 不动 `news_data.json`（会被 Actions 覆盖，手改无意义）
- 不手改 `css/output.css`（构建产物，会被下次构建冲掉）
- 不碰 `motion.js` 的动效机制（`html.js` 渐进增强 / `translate` 而非 `transform` / `prefers-reduced-motion` 降级 —— 这三条约定重构后依然成立）
- **不使用 `git rm`** —— 本机环境下 `git rm <file>` 会连带删除整个父目录（2026-09-29 实测复现两次，是当天 `css/` 目录丢失事件的真正原因）。删文件的正确姿势：备份父目录 → `rm <file>` → `git add -A <父目录>` → commit
- 不做 T2 / T3（换隐喻 / 换视觉语言）
